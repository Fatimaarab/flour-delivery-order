# سامانه صدور حواله تحویل آرد (شرکت آرد طلای سفید ماهان)

این پروژه یک وب‌اپلیکیشن فرانت‌اند (React + TypeScript + Tailwind CSS) و نمونه کدهای بک‌اند (Django Python) جهت صدور، مدیریت و چاپ رسمی **«برگ صدور حواله تحویل آرد»** می‌باشد.

---

## 🌟 ویژگی‌های کلیدی (Features)

1. **صدور حواله دو نسخه‌ای رسمی:**
   - رندر همزمان **نسخه انبار** (جهت بایگانی انبار) و **نسخه باسکول** (جهت بایگانی باسکول) در یک صفحه A4/A5 چاپی.
   - خط برش خط‌چین جهت جداسازی آسان نسخه انبار و باسکول.
   - قابلیت فیلتر نمای چاپی (چاپ هر دو نسخه، فقط نسخه انبار، یا فقط نسخه باسکول).

2. **مدیریت اطلاعات و ثبت توضیحات:**
   - ثبت کامل مشخصات: شماره حواله، تاریخ شمسی، تعداد کیسه آرد، نام راننده، شماره کامیون/پلاک، کد ملی راننده و مقصد تحویل.
   - بخش **توضیحات تکمیلی دلخواه** (نوع آرد مانند خبازی/ستاره/نول، وزن خالص باسکول، درجه کیفی یا یادداشت‌های خاص انباردار).

3. **جستجو و مدیریت هوشمند:**
   - جستجوی سریع در تمام فیلدها (نام راننده، شماره حواله، پلاک، مقصد و متن توضیحات).
   - قابلیت کپی یک‌کلیکه متن کامل حواله جهت ارسال در پیام‌رسان‌ها.
   - قابلیت ویرایش و حذف حواله‌ها.

4. **پشتیبانی کامل از بک‌اند دجانگو (Django Code Generator):**
   - شامل فایل‌های آماده Python/Django:
     - `models.py`: مدل دیتابیس با پشتیبانی از فیلد توضیحات و فیلدهای حواله.
     - `views.py`: ویوهای Class-Based (Detail, List, Create, Update).
     - `urls.py`: مسیریابی‌های استاندارد Django.
     - `admin.py`: تنظیمات پنل مدیریت دجانگو.
     - `receipt_detail.html`: تمپلیت HTML چاپی استاندارد RTL با فونت وزیرمتن و خط برش.

## 🚀 راهنمای اجرا روی سیستم محلی (Local Setup)

### پیش‌نیازها:
- **Node.js** (نسخه 18 یا بالاتر)
- **npm** یا **yarn** یا **bun**

### مراحل اجرا:

1. **کلون کردن مخزن (Clone):**
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.NNAME.git
   cd YOUR_REPOSITORY_NAME
   ```

2. **نصب پکیج‌ها:**
   ```bash
   npm install
   ```

3. **اجرای سرور توسعه (Dev Server):**
   ```bash
   npm run dev
   ```
   برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

4. **ساخت خروجی نهایی (Build):**
   ```bash
   npm run build
   ```
